# FastAPI_S1

## 第一个FastAPI代码：
- 为什么要创建虚拟环境
    - 隔离项目的运行环境，避免不同项目间依赖产生版本冲突，维持该全局环境的干净和稳定
    - Venv与Conda
        - 理由：只是做FastAPI这类Web开发纯Python语言项目，不涉及C++库，不需要使用到Conda；
        - Venv较小，轻量；Conda自带Python版本，不依赖系统版本
        - Venv创建速度快，更适合CI/CD流水线中的环境搭建
        - Venv只支持在本地电脑上允许，不支持迁移，也无法管理多版本python
- 运行FastAPI的方法
    - pycharm run
    - uvicorn main：app --reload
        - reload：编译热重载，不用重启解释器；动态刷新插件模块；交互式的Python shell，不需要重启；
        - 文件监听：监控项目 `.py` 文件变更；检测到文件改动：杀死旧子进程，重新启动整个服务进程；重新导入全部模块，重新初始化 app、路由、配置
            - 注：生产环境不需要热更新；
- FastAPI交互式文档
    - 访问：/docs；
    - 一个 API 使用说明书，允许直接在该网页上点击按钮来测试接口；
    - 不再需要手动完成接口的功能撰写，由FastAPI自己完成并且与前端沟通，传达接口信息；
    - 极为方便的调试工具；

## 路由
- URL地址与处理函数之间的映射关系，决定了当用户访问某个特定网址时，服务器应该执行哪段代码来返回结果。
- FastAPI的路由定义基于Python的装饰器模式
    - 装饰器：FastAPI实例、请求方法、请求路径、响应结果
- 作用:
    - 识别地址：根据URL查找匹配的路由，寻找对应修饰器下的函数；
    - 自动解析用户输入的数据，传送参数；
- 分类：
    - .get:读取数据；
    - .post:提交/创建新数据；
    - .put:更新数据(整体替换)
    - .delete:删除数据
- 大项目时候：API router
    - 把相关的路由打包在一起，然后挂载到主应用上

## 参数
- 同一段接口逻辑，根据参数不同返回不同的数据
- 参数就是客户端发送请求时附带的额外的信息和指令
- 作用：让同一个接口能根据不同的输入返回不同的输出，实现动态的交互
- 分类
    - 路径参数：
        - 作用：指向唯一的、特定的资源
        - 位置：URL路径的一部分 /book/{id}
        - 方法：GET
            - @app.get("/book/{id}")
              async def get_book（id:int）    (参数类型注解：约定id数据类型)
              ......
        - 类型注解 Path（从FastAPI库中import Path库）
            - FastAPI允许为参数声明额外的信息和校验
            - 如何为路径参数添加类型注解：
                - Python原生注解（id：int）
                - Path注解
                    - 特性：路径参数必须传，不可省略
    - 查询参数：
        - 声明的参数不是路径参数，直接添加形参，允许等号赋默认值
        - 作用：对资源集合进行过滤、排序、分页等操作
        - 位置：URL？ 之后；k1=v1&k2=v2
        - 方法：GET
        - 类型注解 
            - Query注解（用于校验、文档描述、设置默认值）
            - Python原生注解
    - 请求体参数：
        - 作用：创建、更新资源；携带大量数据（注册等等）
        - 位置：HTTP请求的消息体（body）中；HTTP协议中，完整的请求由三部分组成
            - 请求体：实际要发送的数据内容
            - 请求行：包含方法、URL、协议版本
            - 请求头：元数据信息（Content-Type，Authorization等）
        - 方法：POST、PUT等
        - 使用
            1. 定义类型
            2. 类型注解
        - 类型注解 pydantic中的 Field函数
            - Field函数，类似于 Path和 Query

## 响应
- 默认情况下，FastAPI会自动将路径操作函数返回的Python对象（字典、列表、Pydantic模型等），经由 jsonable_encoder转换为JSON兼容格式， 并包装成 JSONResponse返回。省区手动序列步骤；也可返回非JSON数据；FastAPI提供了丰富的相应类型来返回不同数据；
- 非JSON响应类型设置方式
    - HTMLResponse 装饰器中指定响应类
        - 场景：固定返回类型（HTML、纯文本等等）
        - 导入：fastapi_responses中导入HTMLResponse；
    - 返回响应对象
        - 场景：文件下载、图片、流式响应（返回不固定）
    - FileResponse 直接返回响应对象
        - FileResponse 是 FastAPI提供的专门高效返回文件内容（如图片、PDF、Excel等）响应类。能够智能处理文件路径、媒体类型推断、范围请求和缓存头部；是服务静态文件的推荐方式。
- 自定义响应数据格式
    - 自定义接口返回数据格式来约束响应的数据格式
    - response_model 是路径操作修饰器的关键参数，它通过一个Pydantic模型来严格定义和约束API端点的输出格式
- FastAPI中，怎么设置响应类型？
    - 装饰器中设置响应类 和 响应返回对象
---
- 异常处理
    - 对于客户端引发的错误（4xx，如资源未找到，认证失败），应使用fastapi.HTTTPException来中断正常处理流程，并返回标准错误响应；
