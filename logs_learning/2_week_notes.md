# FastAPI
- 注意到：> 当 HTTP 请求命中路由，框架内部自动执行你的函数，并把请求数据作为入参传入，函数返回值变成接口返回结果
    - 这就是为什么我们说FastAPI会帮我们调用函数

## 中间件
- 为每个请求前后添加统一的处理逻辑(记录日志】身份认证、跨域、设置响应头、性能监控等等)
- 定义：Middleware 是一个在每次请求进入FastAPI应用时都会执行的函数，在请求达到实际路径操作前允许，并且在响应返回给客户端前在运行一次；
- 书写：
    - 函数的顶部使用装饰器：@app.middleware("http")
    - 多个中间件的代码由下而上进行
        - @app.middleware 装饰器，代码里写得越靠后（越晚执行装饰）的越在外[ 可以视作为一种剥洋葱式的叠加与透过 ]，也就是说越晚写的代码块 越早执行

## 依赖注入
- 共享通用逻辑，减少代码重复
- 与中间件区别：部分路由需要通用逻辑，但并非全集
- 依赖项：可重用的组件（函数/类），负责提供某种功能或数据
    - 注：FastAPI自动帮你调用依赖项，并将结果"注入"到路径操作函数当中
- 优点：
    - 一次编写多次使用
    - 业务逻辑与基础设施代码分离
    - 易于测试，通过模拟依赖替换真实依赖进行测试
- 场景：
    - 处理请求函数：从请求中提取和验证参数（路径参数、查询参数、请求体）
    - 共享业务逻辑：抽取封装多个路由公用的逻辑代码
    - 安全和认证：验证用户身份、检查权限和角色要求
    - 共享数据库连接：管理数据库会话的创建、使用、关闭
- 区别于函数
    - 声明"需要什么材料"，FastAPI 在接口执行前自动调用备料函数，把结果注入进你的参数里
    - 框架是不能理解函数什么时候需要调用哪些参数的，但是框架能理解依赖注入
- 怎么写
    1. 创建依赖项
    2. 导入Depends
    3. 声明依赖项


## ORM（Object-RelationalMapping，对象关系映射）
- 用于面向对象编程语言与关系型数据库之间建立映射
    - 允许开发者通过操作对象的方式与数据库进行交互，无需编写复杂的SQL语句
- 优点
    - 减少SQL代码，代码简洁易读；
    - 自动处理数据库连接和事务
    - 自动防止SQL注入攻击

# TypeScript

## TS初步认识
- TS 是 JS 的超集，在JS的基础上添加了静态类型系统，最终还是通过编译器编译为js文件去运行
- 编译时候就会报错，随时能够补全
- 重构的安全性也较高，适用于中大型项目
- 运行前必须编译为js文件
- 实用场景
    - 前端 Vue3 、React 优先支持TS
    - 后端 NestJS 框架由 JS 编写，配合Node.js做服务器
    - 微信小程序、鸿蒙应用推荐TS
- 启动ts文件：tsx（terminal）

## 基本类型
### 类型声明
- 类型声明是TS很重要的一个特点
    - TS 中变量声明不需要标注它是什么类型，但为了编写方便，可以用冒号"："去进行解释说明
        - 即使 TS 报错也会正常生成 JS，因为语法是正确的；

    - 通过类型声明可以制定 TS 中变量（参数、形参）的类型
    - 指定类型后，当为变量赋值时，TS 编译器会自动检查值是否符合类型声明，符合则赋值，否则报错
    - 简而言之，类型声明可以给变量设置类型，使得器只存储特定类型值
    - 语法：
        - let 变量：类型；
        - let 变量：类型 = 值；
        - function fn(参数：类型，参数：类型)：类型{
            ...
        } //最后一个类型告知的是函数的返回值
    - 自动类型判断：TS拥有自动的类型判断机制
        - 当变量声明和赋值同时进行，TS 编译器会自动判断变量的类型；也即是同时进行时候可以忽略类型声明
    - 类型：
        - number：1，-35，2.5
        - string：'hi',"hi",hi //任意字符串
        - boolean：true，false //布尔值真或假
        - 字面量：其本身，指在源代码中直接写出的固定值，限制变量的值就是该字面量的值
        - any：任意类型
        - unknown：类型安全的any
        - void：空值（undifined），没有值或者是undifined
        - never：没有值，不能是任何值
        - object：任意的 js 对象
        - array：任意的 js 数组
        - tuple：元素，TS的新增类型，固定长度的数组
        - enum：枚举，TS中的新增类型


- 常见错误
    - ts 文件与 js 文件同目录、同名时，两文件中的函数、变量会被视为同一个全局作用域里的重复说明
        - 解决措施：给js文件放在dist中
    - 多个ts文件间视作为一个大全局作用域，各自间变量函数撞名
        - 解决措施：在每个文件最后一行加上"export{};"；// 这只有一个声明"我是独立模块"的作用
    - 缓存报错
        - windows：ctrl + shift + P；输入restart TS server
        - Mac：cmd + Shift + P；输入相同
